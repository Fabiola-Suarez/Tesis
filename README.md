# Análisis comparativo de los tiempos de ejecución en motores de bases de datos relacionales

Tesina que compara PostgreSQL y MariaDB sobre operaciones SQL equivalentes, variando el volumen de datos, el uso de índices y la forma de procesamiento.

| `tesina/bibliografia.md` | Bibliografía |
